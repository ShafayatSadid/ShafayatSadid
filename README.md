## 🚀 Featured Projects

### 🛍️ Monohor — Bengali Heritage E-commerce Platform

Full-stack e-commerce built solo in 17 days for a real Bengali heritage brand. Product variants, guest checkout with server-side price validation, admin dashboard, Resend email notifications, and Steadfast Courier integration.

**Tech:** Next.js · React · Zustand · Tailwind CSS · Express · MongoDB · Better Auth · Cloudinary

**🔗 Live:** [monohor.com.bd](https://monohor.com.bd)

---

### 🕌 Al-Quran Education — Quran Learning Platform

Islamic education platform with courses, teacher profiles, student testimonials, and full admin panel. Free-trial form via Web3Forms.

**Tech:** Next.js · React · Tailwind CSS · Express · MongoDB · Better Auth · Cloudinary · Web3Forms

**🔗 Live:** [alquraneducation.app](https://alquraneducation.app)

---

### 📚 Markazul Lisan — Islamic Institute CMS

Educational institute platform with 11 public pages + 7 admin sections — blogs, courses, teachers, students, books, daily content, and results.

**Tech:** Next.js · React · Tailwind CSS · MongoDB · Better Auth · Framer Motion · Cloudinary · Web3Forms

**🔗 Live:** [markazul-lisan.verel.app](https://markazul-lisan.vercel.app/)

---

### ⚖️ LegalEase — Lawyer Hiring Platform

Online marketplace for legal services. Role-based dashboards (client/lawyer/admin), Stripe payments (hire + publishing fee), verified comment system, and JWT-based authentication.

**Tech:** Next.js · React · Tailwind CSS · Express · MongoDB · Better Auth · Stripe · Cloudinary

**🔗 Live:** [legit-assist.vercel.app](https://legit-assist.vercel.app)
